# SeettuManager

A Digital Financial Discipline System for Rotating Savings Groups (Seettu) in Sri Lanka

---

## 📖 About The Project

SeettuManager is a web-based, mobile-responsive digital platform designed to modernize the management of traditional Seettu (Rotating Savings and Credit Associations) groups in Sri Lanka. It replaces manual record-keeping with a transparent, secure, and efficient digital solution.

### 🎯 Key Features

- User Authentication with JWT and Role-Based Access Control (Admin, Organizer, Member)
- Group and Member Management
- Automated Payment Tracking and Cycle Scheduling
- Financial Discipline Scoring Algorithm
- Dispute Management System
- Digital Report and Certificate Generation (PDF)
- Emergency Fund Requests
- Multi-language Support (Sinhala, Tamil, English)
- Chatbot Assistant for User Guidance
- Audit Trail and Activity Logging

### 🛠️ Built With

| Layer | Technology |
|-------|------------|
| **Frontend** | React.js, Vite, Bootstrap, Chart.js, i18next |
| **Backend** | Spring Boot 3.2.x, Java 17, Spring Security, JWT |
| **Database** | MySQL 8.0+ |
| **Build Tools** | Maven (Backend), npm (Frontend) |
